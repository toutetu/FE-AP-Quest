# Contract: AIチェック

`sample.json(prompt, { modelTier: "default", signal })` を1回呼ぶ。キャッシュは初期設定（5分）のまま。
同じメモで「もう一度」を押したときは `cache: false` で呼ぶ。

## 指示文（テンプレート）

`{...}` の部分をメモの内容で置き換える。利用者の入力は最大でも数百文字なので、そのまま入れる。

```text
あなたは、基本情報技術者試験（FE）と応用情報技術者試験（AP）の学習を手伝う講師です。
受験者が、調べた用語を自分の言葉で説明したメモを書きました。内容を確認してください。

用語: {term}
受験者の説明: {explanation}
受ける試験: {exam または「APとFE」}
受験者が選んだ分野: {中分類の名前 または「未選択」}

次の形のJSONだけを返してください。説明文はすべて日本語で書いてください。
{
  "verdict": "correct" | "partial" | "incorrect",
  "feedback": "説明の良い点と、足りない点・誤りを2〜3文で",
  "suggestedExplanation": "試験で通用する説明（100文字以内）。verdict が correct なら null",
  "pitfalls": ["試験でのひっかけポイント（1つ40文字以内、最大3つ）"],
  "related": ["セットで覚えるとよい用語（最大5つ）"],
  "suggestedFieldMinor": 1〜23の整数（下の一覧の番号）,
  "quiz": 4択問題 または 穴埋め問題のどちらか1つ
}

4択問題の形: {"type": "choice", "question": "問題文", "choices": ["ア", "イ", "ウ", "エ"], "answerIndex": 0〜3, "explanation": "解説（80文字以内）"}
穴埋め問題の形: {"type": "cloze", "sentence": "＿＿＿ を含む1文", "answer": "＿＿＿に入る語", "explanation": "解説（80文字以内）"}

分野の番号: 1 基礎理論 / 2 アルゴリズムとプログラミング / 3 コンピュータ構成要素 / 4 システム構成要素 /
5 ソフトウェア / 6 ハードウェア / 7 ヒューマンインタフェース / 8 マルチメディア / 9 データベース /
10 ネットワーク / 11 セキュリティ / 12 システム開発技術 / 13 ソフトウェア開発管理技術 /
14 プロジェクトマネジメント / 15 サービスマネジメント / 16 システム監査 / 17 システム戦略 /
18 システム企画 / 19 経営戦略マネジメント / 20 技術戦略マネジメント / 21 ビジネスインダストリ /
22 企業活動 / 23 法務
```

## 返答の検査

返答は信用せず、項目ごとに検査する。形が合わない項目は捨て、残った項目だけを保存する。
`verdict` と `feedback` のどちらかが欠けたら、全体を失敗（`retry`）として扱う。

| 項目 | 合格の条件 | 不合格のとき |
|---|---|---|
| `verdict` | 3つの値のどれか | 全体を失敗 |
| `feedback` | 1〜400文字の文字列 | 全体を失敗 |
| `suggestedExplanation` | null または 1〜200文字 | null にする |
| `pitfalls` | 文字列の配列。各80文字以内、最大3件 | 範囲外の要素を捨てる |
| `related` | 文字列の配列。各40文字以内、最大5件 | 範囲外の要素を捨てる |
| `suggestedFieldMinor` | 1〜23 の整数 | null にする |
| `quiz`（choice） | 選択肢がちょうど4つ、`answerIndex` が0〜3、問題文と解説が文字列 | null にする |
| `quiz`（cloze） | `sentence` に「＿」を含み、`answer` が1〜40文字 | null にする |

## 保存と表示

- 保存先は `Memo.ai`。`aiGenerated: true` を付け、画面では「AIが作成」の印を表示する。
- `suggestedExplanation` は、利用者が「この説明を採用」を押したときだけ `Memo.explanation` に入れる。
- 利用者がAIの結果（問題を含む）を書き換えたら `editedByUser: true` にする。
- 「AIの結果を削除」で `Memo.ai` を null に戻せる。
- `suggestedFieldMinor` は、メモの分野が未選択のときだけ「この分野にする？」と提案する。
