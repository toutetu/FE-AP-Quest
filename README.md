# FE-AP-Quest

基本情報技術者試験（FE）と応用情報技術者試験（AP）の合格を目指す、ゲーム調の学習アプリです。

## なぜ作るのか

- 過去問を解きながら調べたことをその場でメモし、忘れたころに自動で復習したい
- 就活の面接・面談が不定期に入っても、勉強のペースを保ちたい
- 2026年12月の受験に向けて、毎日続けられる仕組みがほしい

## 主な機能（第1弾・開発中）

| 機能 | 内容 |
|---|---|
| 10秒メモ | 用語と自分の言葉での説明だけで登録 |
| モンスター討伐 | 1日 → 3日 → 7日 → 14日 → 30日と、間隔をあけて自動で出題 |
| クエストとボス戦 | 今日・今週のノルマ、試験日までの残り日数、レベルと連続日数 |
| AIチェック | メモの説明が合っているかの確認、ひっかけポイント、復習用の問題づくり |
| 予定に合わせたノルマ | カレンダーに面接・面談がある日は、自動でノルマを軽くして週の中で調整 |
| 図鑑とワールドマップ | 分野ごとの進み具合と苦手な分野がひと目でわかる |

## 技術

- TypeScript
- claude.ai の Artifact として公開（記録の保存、AIの呼び出し、カレンダーの読み取り）
- 予定やメールの中身はリポジトリに含めず、アプリを開いたときに本人の権限で読むだけにしています
